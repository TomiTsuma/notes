# ProjectCard

Grid card for a project: name, context, description, Kanban progress, colour band, activity and status. Also exports `AddTile`, the dashed "new" tile.

## Props

`name` · `context` · `description` · `color` · `starred` · `status` (todo|inprogress|review|done) · `activity` · `progress`.

## Usage

- Clicking opens Project detail. ⋯ opens Edit / Delete / Open board.
- Replaces the Dashboard project grid and the Projects list panel.
