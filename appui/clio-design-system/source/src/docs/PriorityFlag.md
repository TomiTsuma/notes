# PriorityFlag

Flag chip for task priority, plus `DeltaChip` (↑/↓ percentage) and `Kbd` (keyboard hint) from the same family.

## Props

`priority` high | medium | low. `DeltaChip`: `value` (number, sign sets direction), `suffix`. `Kbd`: children.

## Usage

- High = rose, Medium = amber, Low = sky; the word is always shown.
