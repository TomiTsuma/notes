# NoteCard

Preview card for a notepad, ruled notebook, PDF annotation set or sticky: tags, serif title, snippet, type and time.

## Props

`title` · `subtitle` · `body` · `highlight` (marker-highlighted lead phrase) · `tags` [{name,color}] · `kind` markdown|notebook|pdf|sticky · `updated`.

## Usage

- Titles and snippets use the Reading (serif) styles; metadata stays sans.
- Used in Dashboard "Recent notebooks", Project detail, Library notepads.
