# IconButton

A 28px square icon-only button for toolbars, card headers and the top bar; always carries an accessible `label`.

## Props

`icon` · `label` (required, becomes title + aria-label) · `active` · `size` "lg" (36px) · `outlined` · `dot` (unread / attention).

## Usage

- Use for sidebar toggle, record, download, theme toggle, card ⋯ menus, undo/redo.
- Pair `active` with toggles (grid/list, panel open).
- Replaces the raw ☰ sidebar toggle and inline-styled icon spans.
