# PaperCard

Row card for a PDF paper: thumbnail, title, authors, arXiv id, pages, annotation count, sync state and tags.

## Props

`title` · `authors` · `arxiv` · `pages` · `annotated` (count) · `status` "local" (waiting to sync) · `tags`.

## Usage

- Clicking opens the paper on the Note Canvas; ⋯ holds Download, Tags, Move, Delete.
