# AIPanel

The right-hand Clio AI panel: resizable, Chat / Smart notes tabs, the linked active file, message list and composer.

## Props

`tab` · `file` · children (node, or a function of the current tab) · `footer` · `onClose`.

## Usage

- Ground is flat `ai-wash`; toggled by "Ask Clio" in the TopBar.
- Replaces RightPanel (inspector) with the same features.
