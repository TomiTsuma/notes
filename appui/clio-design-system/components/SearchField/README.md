# SearchField

A recessed search input with a leading magnifier and an optional keyboard hint.

## Props

`placeholder` · `shortcut` (e.g. "⌘K") · `value`/`onChange` · `style`.

## Usage

- Global search lives in the Sidebar with ⌘K; view-level searches (Library, Projects, Reference modal) sit in the view header.
- Placeholders name what is searched: "Search folders & papers…".
