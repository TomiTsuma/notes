# ProgressDots

Dotted progress meter (from the task-board reference) for project Kanban progress.

## Props

`value` 0–100 · `total` dots · `label`. Wrap in a `w-<tint>` element to colour dots with that project tint.

## Usage

- Show the percentage as text beside the dots.
- Replaces the Dashboard "Kanban Progress" bar.
