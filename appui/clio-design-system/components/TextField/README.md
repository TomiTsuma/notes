# TextField

Labelled text input or textarea for every form in Clio (projects, tasks, events, stickies, Nextcloud).

## Props

`label` · `hint` · `error` (replaces hint, turns red) · `multiline` · `mono` (URLs, arXiv ids, paths) · native input attributes.

## Usage

- Labels are sentence case, never ALL CAPS (the old "PROJECT NAME" style is retired).
- Put format help in `hint`, not the placeholder.
