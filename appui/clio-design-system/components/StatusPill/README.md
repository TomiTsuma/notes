# StatusPill

Rounded pill naming a Kanban status with icon + word (+ optional count) — the column header and status field.

## Props

`status` todo | inprogress | review | done · `count`.

## Usage

- Mapping: todo → Not started (stone), inprogress → In progress (amber), review → Under review (lilac), done → Completed (sage).
- Always icon + word: status is never colour alone.
