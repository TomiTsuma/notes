# DailyCard

Date-titled daily card (YYYY-MM-DD) holding the day’s todos with due times, optional journal prose and a quick-add row. Also exports `TodoList`.

## Props

`date` · `icon` · `prose` · `tasksTitle` · `tasks` [{text,completed,dueTime,soon}] · `showAdd` · `footer` · `tag`.

## Usage

- This is the redesigned DailyTodoCard: add, toggle, edit, delete and due time are all kept (edit/delete appear on row hover).
