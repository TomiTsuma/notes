# ColorPicker

Round swatch radio group for project/tag colours and pen ink colours.

## Props

`colors` (tint names or `pen-*` token names; defaults to the six project tints) · `value`/`onChange` · `allowCustom` (adds the + swatch).

## Usage

- Projects, tags, events and stickies pick from the six tints — never raw hex.
- Pen ink picks from `PEN_COLORS`.
