# Checkbox

Checkbox with a label that strikes through when done — the atom of daily tasks and "Tasks for tomorrow" lists. Also exports `Switch` for on/off settings.

## Props

`checked`/`onChange` or `defaultChecked` · `strike` (default true) · children = label. `Switch`: `on`, `onChange`, `label`.

## Usage

- Use `strike={false}` for filters (calendar project toggles).
- Use `Switch` for settings like Palm rejection, never a checkbox.
