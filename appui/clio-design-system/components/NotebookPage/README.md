# NotebookPage

A paper page for the canvas: ruled (blue rules, red margin) or plain for PDFs, with a page number. Also exports `CanvasTagBar`.

## Props

`width` · `height` · `ruled` · `lineSpacing` · `page` · children (strokes svg, `.cl-page-text`, `.cl-page-sticky`).

## Usage

- Line spacing follows the notebook’s `lineSpacing` (default 32px).
