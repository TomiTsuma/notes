# Logos

The Clio wordmark, taken from the app's `src/assets/logo.png` with its grey background removed. Same drawing, two inks.

- `clio-wordmark-ink.png` — ink `#1f1c18` (the `ink` token, Paper theme). Use it on `surface`, `surface-sidebar` and `paper`.
- `clio-wordmark-paper.png` — ink `#f3efe8` (the `ink` token, Graphite theme). Use it on dark surfaces.

Set it 22px tall in the sidebar and never smaller than 16px. Don't recolour it, stretch it, add effects, or put it on a pastel wash. Leave clear space of at least the height of the "o" around it.
